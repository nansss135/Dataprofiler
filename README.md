# Customer Purchase Behavior Analysis & Churn Prediction

## Project Overview

This project focuses on analyzing customer purchase behavior data collected from multiple sources and preparing it for machine learning applications. The primary objective is to understand customer behavior patterns and frame a machine learning problem to predict customer churn.

The project covers the complete data analysis workflow including data acquisition, data cleaning, exploratory data analysis (EDA), data profiling, and understanding tensors in machine learning.

---

# Problem Statement

A consumer insights company has provided customer purchase behavior data collected from multiple sources. The goal is to analyze the dataset, clean and preprocess the data, perform exploratory data analysis, generate profiling reports, and frame a machine learning problem to predict customer churn.
